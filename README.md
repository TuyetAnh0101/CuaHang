## Overview

CuaHang is an Android application developed as a practical project for exploring mobile application development and store management workflows.

The project combines Kotlin and Android development with Firebase services for authentication, cloud data management, and realtime database operations.

The application also integrates supporting libraries for data visualization, image loading, and JSON processing.

## Project Highlights

The project demonstrates practical experience in Android development, cloud services, and application data management.

### Android Development

- Developed an Android application using Kotlin.
- Built application interfaces using AndroidX and Material Components.
- Applied ConstraintLayout for responsive interface organization.

### Cloud Integration

- Integrated Firebase Authentication for user authentication.
- Worked with Cloud Firestore for application data management.
- Used Firebase Realtime Database for realtime data operations.
- Integrated Firebase Analytics.

### Application Libraries

- Integrated MPAndroidChart for data visualization.
- Used Glide for image loading and display.
- Used Gson for JSON processing.
- Applied AndroidX CardView for reusable UI components.
